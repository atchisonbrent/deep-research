# General

## Choose this mode when

No narrower mode fits, or the question spans several modes without a dominant one. Before settling here, check `event-assessment` (something happened), `state-of-practice` (how is this done well), `technology-landscape` (what exists and how mature is it), and `comparative-analysis` (which option). If one of those fits 70% of the question, use it and note the remainder as scope.

## Evidence hierarchy

Borrow the hierarchy of the nearest mode and write that choice into the report's research contract. Absent a nearer mode:

1. primary records: original documents, data, code, recordings, filings, first-hand accounts;
2. independent reporting or analysis with its own evidence path;
3. specialist analysis with inspectable method;
4. stakeholder statements, kept in attribution;
5. commentary and social media, for leads only.

## Decomposition pattern

Split the question into: what is observed, what is claimed by whom, what is inferred, what is forecast, and what is unknown. Write the decision the report serves; a `general` report without a stated use tends to become a summary of the news cycle.

## Mode gates

- The research contract names the decision, comparison class or scope, and cutoff.
- The nearest borrowed hierarchy is written down, or the report states that none applies.

## Output sections

- Verdict
- What is observed
- What is assessed
- Competing hypotheses (omit if the question is purely descriptive; say so)
- Gaps and falsifiers

## Completion criteria

Every load-bearing claim is observed, reported, assessed, forecast, or unknown; the reader can tell which. Hypotheses exist only if the question is causal, intentional, or forecast.

## Pitfalls

- Using `general` to avoid choosing a hierarchy. The mode is a fallback, not a shrug.
- Manufacturing hypotheses because the skeleton has a heading for them.
