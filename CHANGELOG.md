# Changelog

All notable changes to this project are documented here. This project follows [Semantic Versioning](https://semver.org/) and is released through a human-reviewed Release Please PR.

## [0.1.0] - 2026-08-31

### Features

- Publish the reusable `/deep-research` Hermes skill.
- Add mode-specific workflows for technology, markets, companies, release forecasting, policy, science, products, due diligence, and modern events.
- Add a standard-library-only report CLI, schema, citation ledger, evidence validation, sensitive-content scanning, and CI.
- Publish a real cutoff-bound Iran war assessment as a validated example.
- Separate public framework machinery from private report-vault contents.
